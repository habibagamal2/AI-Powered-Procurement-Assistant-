# Week 5 Graduation Project - AI-Powered Procurement Assistant

## Business Scenario
A procurement department wants an AI assistant to answer procurement policy questions, summarize vendor documents, extract vendor information, and validate purchase requests.

## Main Assets
- `documents/*.pdf`
- `data/Sample_Purchase_Requests.csv`
- `schemas/*.json`
- `prompts/procurement_assistant_system_prompt_template.txt`
- `testing/capstone_test_questions.csv`
- `evaluation/capstone_answer_evaluation_template.csv`

## Required Solution Components
1. Business problem statement.
2. Target users and user journeys.
3. Proposed solution architecture.
4. Azure OpenAI usage.
5. Azure AI Services usage.
6. RAG design.
7. Prompt examples.
8. Vendor document extraction approach.
9. Purchase request validation logic.
10. Testing and evaluation approach.
11. Risks and limitations.
12. Mini proposal section.
13. Final presentation and demo.

## Required Demo Scenarios
Demonstrate at least four:

1. Ask a procurement policy question.
2. Ask about vendor onboarding requirements.
3. Summarize a vendor profile.
4. Extract key fields from a vendor document.
5. Identify missing fields in a vendor registration form.
6. Validate whether a purchase request has required information.
7. Generate a procurement officer summary.
